\begin{abstract}
Rasch models are widely used to analyze questionnaire and test data. Inference based on the standard Rasch model is only valid when the data meet assumptions such as local independence and absence of differential item functioning. Graphical Rasch models provide a framework where local dependence and differential item functioning can be represented explicitly. In this context, "item screening" denotes a coherent workflow for testing for consistency, local dependence, differential item functioning, score-covariate associations, and graph-based model checking. This is done while taking spurious evidence into account. We present a non-technical introduction to the screening procedure and describe an implementation in R.
\end{abstract}

\section{Introduction}

Questionnaires and tests are widely used to measure health, abilities, and experiences. This makes it essential to ensure that they produce reliable, meaningful, and fair results. This can be done by evaluating whether observed data meet the requirements of the Rasch \citeyearpar{rasch-1960} model. A model that satisfies all formal psychometric criteria of the Rasch model can be considered the gold standard of measurement ensuring validity and objectivity.

Among these are the assumptions that there is no local dependence \cite[LD]{lazarsfeld-henry-1968} and that there is no differential item functioning \cite[DIF]{holland-wainer-2012}.

Briefly, local independence means that items are only correlated through the latent trait that the instrument measures \cite{lord-novick-1968} and DIF that respondents from different groups who have the same level of the latent variable have different response distributions on an item.

Graphical Rasch models \cite{kreiner-christensen-2002,kreiner-christensen-2004,kreiner-christensen-2007} provide a framework for including item dependencies and differential item functioning. This class of models does not satisfy all measurement requirements, but offers a realistic and practically useful representation of empirical data \cite{kreiner-2007}. 

Identifying explicit violations of the Rasch model requirements based on empirical data is essential. Each item pair can be tested for LD using several available methods \cite[pp. 179-80]{christensen-et-al-2017}. Similarly, several statistical tests exist that can evaluate of DIF for each combination of an item and a covariate \cite{zumbo-1999}.

In the context of LD, Kreiner and Christensen \citeyearpar{kreiner-christensen-2012} discuss two testing approaches: conditional likelihood ratio tests \citep{kelderman-1984} and a simple non-parametric test that does not require specialized Rasch software \cite[pp. 1250-1]{kreiner-christensen-2004}. These approaches also apply to tests of DIF.

The latter of these approaches is the basis of a stepwise screening procedure for simultaneously evaluating LD and DIF \cite{kreiner-christensen-2011}. This procedure involves checks of consistency, tests of LD, tests of DIF, elimination of spurious evidence, and graph-based checks of the resulting model structure. 

\subsection{Models for measurement}\label{sec:models_measurement}

Let $\Theta$ denote the latent trait that the instrument intends to measure. The Rasch model describes the relationship between this trait and observed item responses $\boldsymbol{Y}=(Y_i)_{i=1,\ldots,k}$. Let $\boldsymbol{X}=(X_i)_{i=1,\ldots,m}$ denote a set of covariates. For ease of exposition, the main text considers dichotomous items, $Y_i\in\{0,1\}$; the general case of ordinal items with more than two response categories is given in Appendix~\ref{sec:AppGeneral}. 

The Rasch model imposes the following requirements: (i) $\theta$ is uni-dimensional; (ii) local independence: $Y_i\perp Y_j|\theta$ for all item pairs $(X_i,X_j)$; (iii) Absence of DIF: $Y_i\perp X_l|\theta$ for all pairs $(Y_i,X_l)$ where $Y_i$ is an item and $X_l$ is a covariate; (iv) the parametric form of the response probabilities is
$$
P(Y_i=y|\theta)=\frac{\exp(y(\theta+\alpha_{i}))}{1+\exp(\theta+\alpha_{i})}
$$
The last requirement ensures that the item response function (IRF) $\theta\mapsto E(X_j=x|\theta)$ is monotone and increasing. Interpreting $-\alpha_i$ as the item location is often useful.

\subsubsection{Notation}

For each participant total scores are computed as $S=\sum_{i=1}^k Y_i$ and rest-scores as $R_i=S-Y_i$. Furthermore, for any subset of items $B\subset\{Y_1,\dots,Y_k\}$ we define sub-scores $S_B=\sum_{Y_i\in B}Y_i$.

\subsubsection{The graphical Rasch Model}

Combining the requirements (ii)-(iv) we can write the Rasch model in vector form
\begin{align}
P(\boldsymbol{Y} = \boldsymbol{y} | \boldsymbol{X} = \boldsymbol{x}, \theta) =\exp\left(\alpha_0+\theta S+\sum_{i=1}^k y_i\alpha_{i}\right) \label{eq:sufficient}
\end{align}
where
$$
\alpha_0=-\log\left(\prod_{i=1}^k\left(1+\exp(\theta+\alpha_i)\right)\right)
$$
is a normalizing constant that does not depended on the observed data $(\boldsymbol{y},\boldsymbol{x})$. It is a consequence of (\ref{eq:sufficient}) that $S$ is sufficient for $\theta$. This is feature that makes the Rasch model stand out from other models for measurement. Explicitly, this means that under the Rasch model, the total score $S$, contains all information in the response patterns, that is relevant for estimating $\theta$. However, it is important to specify that $S$ and $\theta$ are not identical objects, but $S$ is an observed statistic, which holds the necessary information about the unobserved parameter $\theta$, under the Rasch model.

\subsubsection{Adding LD and DIF}

The general form represented in (\ref{eq:sufficient}) is a log-linear model containing only main effects, and this model is easily extended to include (i) interaction terms between item pairs (to model LD) and (ii) interaction terms between item and exogenous variable pairs (to model DIF). This leads to the following form for the graphical Rasch model for dichotomous items

\begin{align}
P(\mathbf{Y}=\mathbf{y}\mid \Theta=\theta,\mathbf{X}=\mathbf{x}) = \exp\Big(\alpha_0+\theta S+\sum_{i=1}^k\alpha_iy_i+(\star)\Big),
\label{eq:also-sufficient}
\end{align}
where
\begin{align}
(\star)=\sum_{i=1}^{k}\sum_{j>i}\lambda_{ij}y_iy_j+ \sum_{i=1}^{k}\sum_{l=1}^{m}\delta_{il}y_ix_l
\end{align}
with $\lambda_{ij}$ is an indicator of LD for the item pair $(i,j)$ and with $\delta_{il}$ is an indicator of DIF for the item $Y_i$ with respect to covariate $X_l$. It is seen from (\ref{eq:also-sufficient}) that $S$ is also sufficient for $\theta$ in this more general model.

\subsubsection{Representation as graph}

The model can be represented as a graph where items and covariates are represented as nodes. Edges between item nodes represent LD, while edges between item and exogenous variable nodes represent DIF.

\section{Methods}

This section describes the item screening procedure. Assume that $V(\Theta)>0$ and make three choices: (i) an association measure and a partial association measure; (ii) a way to calculate $p$-values; (iii) a way to adjust for multiple testing.

Re (i): Analyses below use $\gamma$ \cite{goodman-kruskal-1954} and partial $\gamma$ \cite{davis-1967}. Details about how to compute these are in Appendix \ref{sec:App-gamma}. Re (ii): Analyses below use asymptotic $p$-values, but Monte Carlo $p$-values \cite{north-2002} may be a better choice. Re (iii): Analyses below uses the method suggested by Benjamini and Hochberg \citeyearpar{benjamini-hochberg-1995}, but other methods can also be used. Details about how to compute these are in Appendix \ref{sec:App-multiple-testing}.

\subsection{Analysis of consistency} 

\subsubsection{M1} 

Test that there is a positive correlation between any pair of items. 

\subsubsection{M2} 

Test that any item $Y_a$ is positively related to its corresponding rest-score $R_a$, and all sub-scores $S_B$, where $Y_a\not\in B$.

\subsubsection{M3} 

Test that any exogenous variable $X_l$ that is positively related to $\Theta$ is also positively related to the total score $S$, to all sub-scores, $S_A$, and to all item responses $Y_i$. 

\subsection{Analysis of LD and DIF}

Use partial association coefficients to flag all item pairs exhibiting LD and all pairs of an item and a covariate that exhibit DIF. Test hypotheses of the form

\begin{align*}
    H_0^{DIF}: Y_i \bot X_j  \mid S \qquad \text{and} \qquad H_0^{LD}:Y_i \bot Y_{i'} \mid R_i,
\end{align*}

rejecting when the corresponding $p$-value is below $0.05$ after controlling for multiple testing.

\subsection{Elimination of spurious evidence }

This third step filters out spurious evidence for LD and DIF. This is done in the steps (a), (b) and (c) outlined below.

\paragraph{(a) Elimination of spurious evidence of LD.} From the initial LD screening in step 2, we look at all flagged evidence of LD and create four lists:

\begin{enumerate}
\item[(i)] item pairs with two significant positive partial $\gamma$ coefficients.
\item[(ii)] item pairs with two significant negative partial $\gamma$ coefficients.
\item[(iii)] item pairs with only one significant positive partial $\gamma$ coefficient.
\item[(iv)] item pairs with only one significant negative partial $\gamma$ coefficient. 
\item[(v)] item pairs with no significant partial $\gamma$ coefficients. 
\end{enumerate}

For each pair, compute the weighted partial $\gamma$. Use stepwise inclusion for all the item pairs flagged for LD, prioritizing pairs with two significant coefficients. First, include the strongest evidence of LD at face value. Next, disregard all other tests as spurious if one of the two flagged items defines the conditional rest-score. Move pairs down on the list (i)-(v) above if this happens. Repeat until no flagged pairs remain.


\paragraph{(b) Elimination of spurious evidence for items with more than one
DIF source.} Implemented as Algorithm~\ref{alg:step3b} in Appendix~\ref{sec:AppAlgorithms}; no source is removed from the candidate list until all tests in the current iteration have been performed. Significance is assessed via the Monte Carlo $p$-value procedure of Algorithm \ref{alg:mc_cond_independence} (also in Appendix~\ref{sec:AppAlgorithms}).

\paragraph{(c) Elimination of spurious evidence for sources with an apparent
DIF effect on more than one item} applies the same elimination procedure as (b), but to the $DIF(X_i)$ lists rather than the $SOURCE(Y_i)$ lists, eliminating items exhibiting spurious DIF with respect to each exogenous variable; see Algorithm~\ref{alg:step3b} in Appendix~\ref{sec:AppAlgorithms}.

\paragraph{Combining (b) and (c).} The order of (b) and (c) does not matter, since no final decision is made until both have run. Each item-covariate pair then carries two $p$-values, one from each step, and DIF is accepted as genuine only if both are significant.

\subsection{Association between the score and exogenous covariates}
We examine the structural association between the total score and exogenous variables via backwards elimination: an exogenous covariate is retained as a structural predictor of the score if it remains conditionally associated with the score given the other retained covariates. This is outlined in Algorithm \ref{alg:step4} in Appendix~\ref{sec:AppAlgorithms}.

Retained covariates are treated as evidence of criterion validity and included in the initial GLLRM; dropped covariates are judged to add no significant information about the score once the other candidates are controlled for, and are excluded.

\subsection{Graphical Rasch model and analysis of global Markov properties
of $G_{\mathrm{Rasch}}$}

We now construct the initial GLLRM by collecting the outputs of Steps 3 and 4 into the corresponding graph, IRT graph, and moralized marginal graph.

\paragraph{\textit{Step 5 in practice}}
No new tests are performed; we simply report the structure implied by the genuine LD and DIF edges and the exogenous variables satisfying criterion validity. The GLLRM graph records which nodes are present and connected beyond the item--latent-trait edges. The IRT graph has the same nodes and edges, with measurement, score-association, and DIF edges directed and LD edges undirected. The moralized marginal graph is obtained by marrying parents, replacing the latent trait with a score node, and adding undirected score-to-item and item-to-item edges.


\subsection{Tests of global Markov properties of the GLLRM}
Before reporting an initial model, we retest the DIF and LD relations retained from Step 5 against the full structure, to check they are not artifacts of the simpler conditioning sets used earlier. For DIF, this is the test
\begin{align}
    H_0^{C5}: Y_i \perp X_j
    \mid
    S,\ \operatorname{DIF}(X_j)\setminus\{Y_i\},\
    \operatorname{SOURCE}(Y_i)\setminus\{X_j\}. \label{C5}
\end{align}

\section{Discussion}
The M2 and M3 checks are implemented as screening procedures measuring the associations between items and their corresponding rest-scores, and exogenous covariates and the total score respectively. This means we are not performing the exhaustive test of checking items and exogenous covariates against all possible sub-scores. This keeps the procedure computational feasible, as the number of unique sub-scores, for $k$ items, not including the item in question and the $0$ sub-score is $2^{k-1}$, which grows exponentially with the number of items. 

The stepwise inclusion algorithm, identifying genuine LD in step 3a, groups pairs with two significant LD tests and weigh them equally but prioritize them over item pairs only exhibiting one significant LD test, which are also grouped. In both groups the strongest evidence of genuine LD is determined by the absolute value of the weighted partial gamma coefficient of the two tests. This means that both positive and negative association LD can be prioritized as the strongest signal. The idea is that an item pair with two significant tests must have a stronger LD signal than item pairs with only one significant test. While allowing item pairs to drop from the set of two significant tests into the set with only one. The use of weighted partial gammas allow us to compare the LD pairs equally and also ensures the contribution of a test to the decision statistic is influenced proportionally to the number of comparable pairs defining the partial gamma, thus keeping as much information in the decision statistic as possible. Opposed to comparing pairs based on their naive arithmetic mean. 

A negative partial gamma association between two items means that scoring high on one of the two will lead you to scoring low on the other. When does this makes sense? In a setting where two questions test different methods. But then we are no longer modeling a unidimensional latent trait, but a multi dimensional one \cite{kreiner-christensen-2004}, and it should be well considered if the questionnaire should be handled as a whole or split into sub questionnaires.  


For DIF, one of the two important decisions made, is that 3b and 3c are complementary steps and not individual, meaning no decisions are made until both have been performed and compared. We only retain a DIF edge if it survives both steps, which is a rather conservative choice. However, the general overall procedure is to start with a large set of LD and DIF (step 2) and then proceed to narrow the sets down as we get deeper into the screening. As all LD and DIF edges are tested again in later steps. The advantage being that we are less likely to include spurious DIF edges, but at the cost of potentially removing weaker but genuine DIF relations. The second important of the two decisions made in the DIF framework is how we estimate $p$-values. As strata quickly become so thin that asymptotic $p$-values are unreliable, we've chosen to rely on Monte Carlo estimation of the exact $p$-values. While Monte Carlo methods may provide an easy framework for approximating $p$-values it also introduces some simulation uncertainty. In other words, the number of resamples $B$ affects the stability and therefore precision of $p$-values, not to mention how the unique resampling actually looks for a specific $p$-value. Alternative methods include; asymptotic $p$-values (which should be noted: is implemented for reproducibility purposes!), bootstrapping and/or other resampling procedures. Asymptotic tests are faster, almost instantaneous, but may be less reliable in large sparse contingency tables, while bootstrapping or resampling methods may be more computationally demanding tasks and require additional choices to be made about what exactly we want to resample. 

Finally, the graph-building and graph-checking steps, i.e. 5 and 6, does not draw the graphs explicitly, this is something we have, as of now, left to the user. They do however report the nodes, where edges should be present, which type they are and if they should be directed. Step 5 reports this information based on the retained LD, DIF, and score-covariate evidence. It should be stressed, the graph structure reported, is to be understood as an evidence graph which is the result of the previous steps and not as the final model. Step 6 then retests the retained edges using conditioning sets implied by the graph. Meaning that right now step 6 acts as a confirmation of the posed graph from step 5. 

\section{Conclusion}
This project has shown that the item screening procedure within the framework of graphical log-linear Rasch models can be implemented in R. The result is an R package that provides a coherent and reproducible toolkit for carrying out such screenings. The package addresses the need for a more transparent workflow for researchers working with Rasch models and its corresponding assumptions. 

\subsection{Beyond twigg}
A natural extension of twigg would be to include formal tests of minimal GMP hypotheses. This would make it possible for the package to support not only the screening procedure itself, but also later stages of model evaluation. However, this is not essential for the current contribution of the package. In its present form, twigg should be understood as a tool for carrying out and documenting the screening process, while the final interpretation and subsequent analysis remain the responsibility of the user.

Future development could also focus on improving the integration between twigg and existing Rasch model packages, adding clearer reporting tools, and providing more extensive graphical summaries of the screening results. Such extensions would further support transparency, reproducibility, and practical usability for researchers applying graphical log-linear Rasch models.
