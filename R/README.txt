To use the package R must be installed. Inside R  run the following line of code to install the latest version of the package:
devtools::install_github("SebastianKvist99/twigg")


The package borrows some functions from other, already implemented, packages. So it might be necessary to also install the following packages if they are not already on your device.
* stats,
* DescTools,
* iarm,
* coin,
* purrr


The data analysed in the report is available on the following link
https://erda.ku.dk/public/archives/bacc560d26b01f7a65e77a9712a92e86/published-archive.html


In order to run the R script with the analysis one must have download the twigg package and the dataset above.


The source code for the package is available on github in the following repository https://github.com/SebastianKvist99/twigg.
